# Mesón de Aragón — nueva web

Web estática (HTML + CSS + JS, sin dependencias) para el restaurante Mesón de Aragón (María de Huerva, Zaragoza).

Abrir `index.html` en el navegador para verla.

## Estructura
- `index.html` — página única: inicio, nosotros, carta, menú del día, celebraciones, contacto/reservas
- `css/styles.css` — estilos (responsive)
- `js/main.js` — menú móvil, pestañas de la carta, formulario de reserva (vía WhatsApp), animaciones
- `img/` — poner aquí `hero.jpg`, `interior.jpg`, `plato.jpg` (sin ellas se muestran degradados)

## Pendiente de confirmar con el restaurante
- Platos y precios de la carta (marcados `--,-- €`)
- Precio del menú del día
- Horario
- Número de WhatsApp para reservas (`js/main.js`)
- Fotos reales
- Textos legales (aviso legal, privacidad, cookies)
