# Mesón de Aragón — nueva web

Web estática (HTML + CSS + JS, sin dependencias) para el Hostal Restaurante Mesón de Aragón
(María de Huerva, Zaragoza). Contenido y fotos tomados de la web actual, https://www.mesondearagon.es/

Abrir `index.html` en el navegador para verla.

## Estructura
- `index.html` — página única: portada, bienvenida, restaurante y precios, alojamiento, galería, María de Huerva, contacto
- `css/styles.css` — estilos (responsive)
- `js/main.js` — menú móvil, carrusel, galería con visor ampliado, formulario de reserva (abre el correo)
- `img/` — logo y fotos de la web original

## Pendiente de revisar con el restaurante
- Precios (copiados de la web actual; pueden estar desactualizados)
- Incoherencias en la web original: "14-18" vs "16-20" platos a elegir; eventos "26-40 €" vs "25-40 €";
  Feria de Muestras a "11 km" vs "15 km"
- Horario (la web original no lo indica)
- Textos legales (aviso legal, privacidad, cookies)
- Fotos más recientes y en mayor resolución (las actuales son de 2014-2015, máx. 1096 px)
